# Contributing to Seal

Write the code yourself. Do not copy code from another engine or from a project whose license does not allow it.

The code is under `LICENSE.md` (`LicenseRef-Seal-Proprietary`). By sending a contribution you license it to the licensor as described in section 9 of that file. Do not add an open-source license file, and do not add a copyleft dependency.

`Cargo.lock` is committed. CI builds with `--locked`.
