# Play mode tint

While you run the game from the editor (Play or Pause), the interface uses a coloured tint on panel backgrounds, the toolbar, the viewport frame, and the status bar. The tint shows that scene edits during play are temporary and are discarded when you press Stop.

## Settings

Open **Preferences** from the toolbar settings menu (or the **Settings** panel). Under **Appearance**:

- **Play mode tint colour** — three fields for red, green and blue (each 0–255).
- **Play mode tint strength** — percent from 0 to 100. At 0 the tint is off. The default is a mild mix.

Changes apply immediately while you adjust the values. The tint appears only during Play or Pause and disappears when play stops.

## Status bar

During Play the status bar shows **Playing: changes are not saved**. During Pause it shows **Paused: changes are not saved**.
