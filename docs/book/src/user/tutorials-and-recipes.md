# Tutorials and recipes

## Tutorial panel

New projects from a wizard template include a tutorial under `tutorial/guide.sealtutorial`. Progress is stored in `tutorial/progress.sealtutorial` in the project folder.

Open **Help → Open Tutorial** or the **Tutorial** panel (it opens automatically when a guided project loads). Numbered steps list what to try; a check mark appears when the editor detects the action (starting play, selecting an object, moving with WASD, and similar).

## Recipes

**Help → Recipes** opens the Recipes panel. Each entry describes a small example: door and key, inventory pickup, moving platform, or checkpoint.

Choose **Import into project** to copy the recipe’s graphs under `logic/` and add its objects to the open scene. The scene is marked unsaved until you save it.
