# Playing your game

Press the Play button on the toolbar to run the open scene inside the viewport.

While the game runs you can **Pause**, **Step Frame** and **Stop** from the same toolbar. Step Frame advances exactly one frame, including physics, scripts, animations and particles. Stop puts every object back where it was before you pressed Play, so nothing you try during play changes the saved scene.

**Play From Here** (command palette, Ctrl+Shift+P) starts play with the player at the selected object.

Messages from scripts, sequences and effects appear in the Console panel while the game runs.
