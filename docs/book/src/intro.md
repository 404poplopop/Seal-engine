# Seal

Seal is a from-scratch game engine. This book describes the pieces that exist in the repository.

The editor shell is the window, the docked workspace, and the crash-safe layout store. The scene world is a hierarchy of entities the outliner edits and the play loop steps. The viewport draws the scene in 3D, or flat and straight-on for 2D games with sprites. Start with the user guide to make and play a game; the editor shell chapters explain how the editor itself is built.

Supported operating systems and hardware are in [System requirements](user/system-requirements.md). Scene axes and units are in [Coordinate system and units](user/coordinate-system.md).
